# Prompt Pack

Status: reusable prompts for future image, video, or storyboard generation.

Every prompt should be paired with `docs/forbidden_simplifications.md`.

## System Constraint Block

```text
Do not depict Apparent-Origin Cosmology as "the Big Bang is fake" or as proof
of hidden physical layers below the Big Bang. The image is a visual compression
of a bounded-observer reconstruction mechanism. Standard cosmological
observations remain binding. Show a reconstruction horizon, not a magical
source or denial of physics.
```

## Image Prompt: Apparent-Origin Surface

```text
A precise scientific visualization of Apparent-Origin Cosmology. A bounded
observer reconstructs a visible cosmos above a luminous reconstruction horizon.
Below the horizon, fine unresolved process-structure is compressed into a
single apparent floor. The style is sober, technical, and cinematic, with
legible diagram labels: "visible reconstruction", "observer threshold",
"apparent-origin surface", "unresolved depth". The image should communicate:
boundary of reconstruction, not beginning of being.
```

## Image Prompt: Apparatus-Bound K

```text
A technical cosmology diagram showing three observation pipelines with different
instrument stacks and inference models. Each pipeline reaches a different
deepest reliable reconstruction surface labeled t_K1, t_K2, and t_K3. The
visual should emphasize that the surfaces are calculable pipeline limits, not
proof that standard cosmology is false. Include subtle telescope, data, and
modeling motifs. Sober scientific palette, high clarity.
```

## Image Prompt: Atlas Fracture

```text
A visual metaphor for atlas fracture in observer-bounded reconstruction.
Several coordinate charts overlap coherently near the observer, with clean
transition maps. Near a deep horizon, the charts begin to fail to compose. The
image should distinguish a legitimate reconstruction horizon from failed
charting. Technical, restrained, high-resolution, no mystical symbolism.
```

## Short Video Prompt: False Bottom

```text
Create a 20-second scientific visual explainer. Begin with a smooth cosmic
reconstruction from local galaxies toward earlier epochs. As the camera moves
deeper, fine structure compresses into a luminous reconstruction horizon. Text
appears: "A boundary of reconstruction is not automatically a beginning of
being." Show the observer apparatus and the finite reconstruction budget K.
End with a burden table briefly flashing: redshift, CMB, BBN, BAO, lensing,
supernovae. Tone: rigorous, not conspiratorial.
```

## Negative Prompt

```text
No "Big Bang is fake" framing. No religious creation imagery. No simulation
glitches. No mystical portal. No anti-science tone. No claim of empirical proof.
No hidden universe shown as established fact.
```
