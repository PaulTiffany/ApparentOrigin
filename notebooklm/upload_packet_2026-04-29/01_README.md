# Observer Cosmology

This repository is the working home for Apparent-Origin Cosmology (AOC): a
bounded-observer research program treating apparent cosmic origins as possible
reconstruction horizons rather than automatic ontological beginnings.

Canonical thesis:

> The Big Bang boundary may be an apparent-origin surface: the deepest coherent
> reconstruction available to bounded observers, not necessarily the ontological
> beginning of the universe.

Canonical slogan:

> Boundary of reconstruction, not beginning of being.

## Current Status

This is not a finished cosmological model and does not claim that standard
cosmology is false. The current repository establishes a Principia-aligned
observer-horizon frame, a proof spine, a first FRW observer-quotient chart, the
load-bearing `K` question, and first real-data empirical contracts.

The current orientation is:

> AOC treats the Big Bang as a candidate observer-relative escape horizon: the
> first coherent surface from which our class of observables can be
> reconstructed.

This makes distance deformation a secondary empirical map, not the whole
theory. Pantheon+ remains an exploratory luminosity-distance branch. DESI DR2
BAO is now a restrictive external gate: after fitting a global BAO scale
nuisance and gridding `Omega_m`, DESI does not support the Pantheon+
deformation direction under the current maps. The result is useful because it
rejects naive cross-probe portability and pushes the program toward
observable-specific maps and operator-residue tests.

## Program Discipline

AOC becomes physics only where it produces controlled, quantitative contact
with observation. Until then, it is a formal and interpretive framework with a
specific empirical burden.

The near-term technical target is apparatus-bound `K` plus external
cross-probe discipline: determine whether a concrete observation pipeline has a
calculable reconstruction floor, whether different pipelines imply different
effective `t_K` values, and whether the Pantheon+ deformation direction
fails to survive the first DESI DR2 BAO projection at Pantheon amplitude.

The next Principia-aligned empirical target is operator-residue analysis:
compare multiple reconstruction operators applied to the same sky or catalog,
then ask which boundary-adjacent features survive the operator change. The
candidate first target is Planck CMB component-separated maps, using Commander,
NILC, SEVEM, and SMICA as explicit observer operators.
