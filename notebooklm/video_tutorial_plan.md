# Video Tutorial Plan

Status: cautious-public draft sequence.

Goal:

Create a tutorial series that explains AOC without implying empirical
establishment.

## Episode 1: What Is an Apparent Origin?

Length: 6-8 minutes.

Allowed claim:

Bounded reconstruction can turn unresolved depth into an apparent boundary.

Avoid:

Claiming that the Big Bang is fake.

Scenes:

1. Define bounded observer.
2. Show unresolved distinctions below threshold.
3. Show observer quotient.
4. Introduce apparent-origin surface.
5. State nonclaims.

Required line:

> A boundary of reconstruction is not automatically a beginning of being.

## Episode 2: The False-Bottom Toy Model

Length: 6-8 minutes.

Allowed claim:

The shifted-softplus toy model demonstrates how a smooth quotient can create an
apparent floor.

Avoid:

Treating the toy model as cosmological evidence.

Scenes:

1. Plot identity map.
2. Introduce epsilon floor.
3. Apply shifted softplus quotient.
4. Show sub-threshold compression.
5. Explain what the model does not prove.

## Episode 3: The First FRW Chart

Length: 10-12 minutes.

Allowed claim:

In a first FRW observer-access chart, finite reconstruction budget `K` induces a
minimum reconstructible time `t_K`.

Avoid:

Claiming the chart replaces LambdaCDM.

Scenes:

1. Introduce FRW scale factor `a(t)`.
2. Define `Omega_O(t)=a(t)^2`.
3. Define access cost `kappa_O^{access}=1/a(t)`.
4. Introduce finite `K`.
5. Derive `t_K`.
6. Explain caveats.

Required caveat:

The access-cost law is inherited from the Figure 3 observer-access formalism; a
native cosmology derivation remains open.

## Episode 4: Why K Is the Hard Problem

Length: 8-10 minutes.

Allowed claim:

If `K` is calculable, AOC can begin making operational predictions about
reconstruction floors.

Avoid:

Claiming AOC explains current cosmological tensions.

Scenes:

1. Show how `K` sets `t_K`.
2. Explain why arbitrary `K` is not predictive.
3. Introduce apparatus-bound `K`.
4. Show pipeline-dependent floor shape.
5. State why Hubble tension is only a long-term comparison shape.

## Episode 5: The Empirical Burden

Length: 10-12 minutes.

Allowed claim:

AOC must reproduce, reinterpret, or predict deviations for standard
cosmological observations.

Avoid:

Skipping hard observables.

Scenes:

1. Redshift-distance relation.
2. CMB.
3. BBN.
4. BAO.
5. Lensing and structure.
6. Supernova dimming/time dilation.
7. High-redshift galaxy ages.
8. Current status: open.

## Episode 6: Images, Story, and Discipline

Length: 6-8 minutes.

Allowed claim:

Visuals can recruit attention and preserve intuition.

Avoid:

Treating visuals as proof.

Scenes:

1. Show existing AOC image.
2. Explain caption discipline.
3. Explain forbidden simplifications.
4. Explain agent/media loop.
5. Close with next technical tasks.
