# Empirical Burden Table

Status: standing checklist. AOC must pay this bill before it can claim to be a
cosmological model rather than an observer-bounded interpretation.

## Rule

For each standard cosmological datum, AOC must eventually do one of four things:

1. reproduce the standard account,
2. reinterpret the datum without degrading fit,
3. predict a controlled deviation,
4. explicitly mark the item as unresolved.

## Near-Term Test Shape

In the apparatus-bound framing:

```tex
K_{app} \sim 1/a_{min}^{reconstructible}.
```

Therefore:

```tex
K_1 \ne K_2
\quad \Rightarrow \quad
t_{K_1} \ne t_{K_2}.
```

The possible empirical shape is pipeline-dependent boundary inference. A mature
version must predict sign and order of magnitude before making contact with
live cosmological tensions.
