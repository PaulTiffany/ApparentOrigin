# AOC Principia Alignment Audit

Status: canonical alignment note.

Purpose:

Keep Apparent-Origin Cosmology aligned with the Principia Symbolica frame
instead of letting it drift into a generic distance-deformation model.

This document does not replace the proof spine or empirical contracts. It
states the current conceptual map that those documents must respect.

## 1. Current Orientation

AOC is best read as a cosmological instance of bounded-observer theory.

The core move is not:

```text
find a better curve for cosmic distances
```

The core move is:

```text
ask whether the observed origin is the first escape surface available to a
bounded observer inside a horizon-structured process
```

Distance tests, BAO tests, CMB tests, transient tests, and galaxy-age tests are
secondary empirical contracts. They are useful only when the observable map is
derived from the observer-horizon picture.

Canonical sentence:

> The Big Bang is treated as a candidate observer-relative escape horizon, not
> as a denied event or a directly inspectable pre-boundary state.

## 2. Principia Anchors

The relevant Principia frame has four anchors:

1. **Observer horizon.**
   A bounded observer has a dynamic horizon `H_O(t)`. Reconstruction happens
   inside that horizon and is shaped by drift, reflection, curvature, memory,
   and instrumentation.

2. **Dual-horizon cosmogenesis.**
   The observable universe may be modeled as a domain between a generative
   boundary `H_G` and a dissipative boundary `H_D`. AOC inherits this as a
   model class, not yet as an established physical claim.

3. **Time as memory.**
   Time is not assumed to be a shared primitive across observers. Operational
   time is reconstructed through traces, memory, ordering, and irreversible
   bookkeeping.

4. **SRMF operator loop.**
   The feasibility chain is:

   ```text
   operation -> instrumentation -> composition -> analysis
   ```

   In SRMF language, this is the feasibility-band expression of the operator
   quartet:

   ```text
   TTDC -> Operation
   TTIE -> Instrumentation
   TTCS -> Composition
   TTPR -> Analysis
   ```

   A claim becomes usable only when it survives the appropriate phase of this
   loop.

## 4. What Counts as Explicit

In this repository, "explicit" does not mean metaphysically final. It means
socially, instrumentally, and operationally stabilized enough to be inspected.

Operational test:

1. Can the claim be acted on or simulated?
2. Can the relevant distinction be instrumented?
3. Can the result compose with other charts without atlas fracture?
4. Can the claim be analyzed against controls?

If the answer is no, the claim remains a TTCS hypothesis or model-class
metaphor, not a canonical result.

Canonical sentence:

> Explicit means stabilized by shared operation, instrumentation, composition,
> and analysis.

### Feasibility-layer attribution

When a residual falls outside the current contract, first ask which layer is
failing before interpreting it.

| Layer | Question | Planck operator-residue example |
| --- | --- | --- |
| Operation / TTDC | Is the mathematical operation/statistic itself well-defined and stable? | `m=ell` axis maximization vs tensor-largest-eigenvalue convention |
| Instrumentation / TTIE | Does the apparatus/extraction surface change what can be measured? | synthetic galactic cut, pseudo-alms, high-ell leakage, official mask choice |
| Composition / TTCS | Does the residue carry/compose coherently across operators, charts, or observers? | Commander/NILC/SEVEM/SMICA agreement or pair-residue disagreement |
| Analysis / TTPR | Does the claim survive nulls, controls, and allowed/forbidden-claim discipline? | coefficient-space, masked-sky, leakage, and future official-mask nulls |

The pivot-regime number is therefore contract-dependent. A recurring value
such as `1/9` may be a useful marker of an out-of-contract band, but the
scientific question is whether the residue is operational, instrumental,
compositional, or analytic.

## 5. Testability Posture

AOC does not attempt to directly observe what it places beyond an observer
horizon. Its empirical target is second-order boundary behavior.

Good evidence shape:

1. Same sky, different reconstruction operators, stable residual structure.
2. Same observable class, different pipelines, calculable reconstruction floors.
3. Horizon-adjacent compression that survives ordinary nuisance controls.
4. Boundary behavior that remains atlas-coherent under chart changes.

Bad evidence shape:

1. A prettier metaphor.
2. A one-dataset curve fit.
3. A post hoc diagnosis of critics or instruments as "thin."
4. A claim that the Big Bang is fake.
5. A claim that inaccessible pre-boundary structure has been directly observed.

## 6. Near-Term Consequence

The next empirical direction should prioritize observer-operator comparisons
over universal deformation fitting.

Most aligned next test:

> Use Planck component-separated CMB maps as different reconstruction operators
> on the same sky, then ask which low-order residual features survive across
> Commander, NILC, SEVEM, and SMICA.

Plain English:

> If AOC is about observer-relative horizons, the clean first question is not
> "can we shift every distance curve?" It is "what remains stable when the same
> universe is reconstructed by different operators?"

## 7. Guardrail

Do not promote a speculative geometry term into a physical claim until the repo
contains:

1. a defined process space,
2. an observer quotient,
3. a reconstruction order,
4. an observable map,
5. controls,
6. a failure condition.

This applies especially to torqued horizons, white-hole leakage, resonance
claims, and Gabriel's-horn language.
