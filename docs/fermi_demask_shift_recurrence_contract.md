# Fermi Demask-Shift Recurrence Contract

Status: pre-run experiment contract.

Phase: near-cousin / empirical-control bridge. This is not an
instantiation-grade cosmological claim. It freezes an operator-residue detector
to ask whether a mask/demask transition induces shared motion across
independent-enough gamma-ray sky reconstructions.

Human-authorial override:

The user has explicitly chosen to proceed despite a prior qualifier from
Desktop GPT. This override is treated as authorship of bounds: it authorizes
the experiment lane. It does not waive the empirical burden, null controls,
voice-independence accounting, or forbidden-claim discipline.

Core question:

```text
When the Milky Way band is masked or demasked, do independent sky
reconstructions move together in a stable directional-motion coordinate, or is
the heard note only a composite artifact of masking, mapping, and listener
perception?
```

The event chain is:

```text
sky data
-> reconstruction operators
-> mask/demask transition
-> shared shift metric
-> recurrence verdict
-> sonification
-> observer-heard note
```

The measured object is the shared shift before sound.

## 1. Positive-Control Gate

Before any Fermi verdict is allowed, rerun the Planck demask-shift positive
control using the existing Planck operator-residue machinery:

```text
target: Planck CMB component-separated maps
operators: Commander, NILC, SEVEM, SMICA
mask transition: declared unmasked/base condition -> declared galcut or
official-mask morphology condition
coordinate: low-ell directional-axis motion under mask transition
```

Required gate:

```text
The frozen Planck detector must reproduce the prior shared-shift /
voice-leading pattern under its declared extractor and mask contract.
```

Failure of the Planck positive control does not refute AOC. It blocks Fermi
interpretation. In that case the Fermi branch may continue only as pipeline
development.

## 2. Fermi Target

Target type:

```text
Fermi LAT residual-sky maps or map-like products after explicit exposure,
diffuse-background, and source-treatment choices.
```

Fermi is used here as an instrument-forward reconstruction domain, not as
direct origin cosmology.

The first Fermi run must choose one concrete map product family before
analysis. "Fermi" alone is too broad. Acceptable first families include:

```text
1. public binned LAT counts/exposure products with fixed energy bands,
2. diffuse-model residual maps generated by a declared pipeline,
3. source-masked residual maps from a declared catalog cut,
4. Galactic-center / bubble-region residual maps under declared templates.
```

## 3. Voices

A voice is a declared reconstruction of the same target sky under a different
operator, energy partition, background model, or source treatment.

Candidate voices:

```text
V1: energy band A residual map
V2: energy band B residual map
V3: diffuse background model A residual map
V4: diffuse background model B residual map
V5: source-masked residual map
V6: bubble / Galactic-center template residual map
```

Voice-independence ledger:

Every run must include a table with one row per voice:

```text
voice | sky target | energy range | event class/type | exposure model |
diffuse model | source catalog/mask | template assumptions |
shared machinery with other voices | independence grade
```

Independence grades:

```text
A: different reconstruction operator and different major nuisance model
B: same instrument/exposure, different nuisance model or energy partition
C: mostly same pipeline with one controlled variation
D: diagnostic only; not counted as an independent voice
```

Only grades A-C enter the primary SharedShift statistic. Grade D voices may be
reported but cannot drive success.

## 4. Mask States

Mask states are the chord states of the experiment.

Primary ladder:

```text
M0: analysis-minimal mask, not necessarily literal full sky
M1: Galactic latitude mask |b| > 10 deg
M2: Galactic latitude mask |b| > 20 deg
M3: Galactic latitude mask |b| > 30 deg
M4: official/source/diffuse mask variant declared before analysis
```

The term "unmasked" is avoided for Fermi unless a literal full-sky diagnostic
map is deliberately included. The gamma-ray Galactic plane is too dominant for
raw full sky to be the default baseline.

Primary transitions:

```text
M0 -> M1
M1 -> M2
M2 -> M3
M0 -> M2
M0 -> M4
```

Adjacent transitions carry the primary decision weight. Long jumps are
secondary diagnostics.

## 5. Directional Signature

For each voice `v`, mask state `M`, and low-order band `L`, compute:

```tex
u[v,M,L]
```

where `u` is an axial direction on the sphere:

```text
u == -u
```

Allowed extractors:

```text
1. principal axis of low-order spherical harmonic power tensor,
2. multipole-vector-derived axis,
3. residual-axis direction from a declared low-order fit,
4. a Planck-positive-control-compatible extractor ported to Fermi maps.
```

The extractor must be frozen before the Fermi data are evaluated.

Distance convention:

```tex
d_axial(a,b) = arccos(|a dot b|)
```

## 6. Demask Motion

For a transition `Ma -> Mb`:

```tex
Delta[v,Ma->Mb,L] = d_axial(u[v,Ma,L], u[v,Mb,L]).
```

If the motion is nondegenerate, define:

```tex
r[v,Ma->Mb,L] = normalize(u[v,Ma,L] x s u[v,Mb,L])
```

where the sign `s in {-1,+1}` is chosen so that:

```tex
u[v,Ma,L] dot s u[v,Mb,L] >= 0.
```

Degeneracy rules:

```text
if Delta < Delta_min: report magnitude; rotation axis is undefined
if Delta > 90 deg - epsilon under axial convention: flag as unstable
if fewer than 3 nondegenerate voices remain: R_axis is inconclusive
```

Default pre-run constants:

```text
Delta_min = 2 deg
epsilon = 2 deg
```

These constants may be changed only before the first live Fermi run, and the
change must be recorded in this document or a versioned successor.

## 7. SharedShift Statistic

For each transition and low-order band:

Endpoint dispersion:

```tex
D_op(Ma->Mb,L)
= median_{i<j} d_axial(u[v_i,Mb,L], u[v_j,Mb,L]).
```

Motion-magnitude dispersion:

```tex
D_motion(Ma->Mb,L)
= median_v |Delta[v,Ma->Mb,L] - median_v Delta[v,Ma->Mb,L]|.
```

Rotation-axis concentration:

```tex
R_axis(Ma->Mb,L)
= 1 - median_{i<j} d_axial(r[v_i], r[v_j]) / D_iso.
```

Use:

```text
D_iso = 57 deg
```

as the same fixed axial-median reference used by the Planck operator-prism
contract unless a Fermi-specific isotropic calibration is predeclared before
analysis.

Primary read:

```text
low D_motion + high R_axis + nontrivial Delta
```

Secondary read:

```text
low D_op
```

Endpoint clustering alone is not success, because it can be produced by mask
geometry.

Required result table:

```text
mask transition | L | n voices | D_op | D_motion | R_axis |
median Delta | null percentile | verdict
```

Default tail definitions:

```text
R_axis tail    = fraction of null runs with R_axis >= observed R_axis
D_motion tail  = fraction of null runs with D_motion <= observed D_motion
joint tail     = fraction of null runs satisfying both inequalities
```

The primary percentile gate applies to the joint tail after declared
look-elsewhere accounting.

## 8. Nulls

The null suite must be run before sonification.

Primary nulls:

```text
1. phase-randomized residual maps,
2. sky-rotated masks,
3. latitude-band shuffles,
4. energy-label shuffles,
5. source-catalog scramble,
6. Poisson simulations using Fermi exposure,
7. synthetic diffuse backgrounds,
8. background-model swap nulls,
9. same sonification mapping on null maps,
10. same data with alternative sonification mappings.
```

The numeric verdict uses nulls 1-8. Nulls 9-10 test the listening layer only.

Allaying outcomes:

```text
shared shift disappears under phase randomization,
shared shift appears equally often in nulls,
shared shift follows mask geometry rather than sky structure,
shared shift depends on one background model,
shared shift is carried by grade-D voices,
heard note changes while numeric recurrence does not,
heard note persists when numeric recurrence is absent.
```

## 9. Success, Failure, Inconclusive

Success requires all of:

```text
1. Planck positive-control gate passes.
2. Fermi primary transition has R_axis above the predeclared null percentile.
3. D_motion is below the predeclared null percentile.
4. Median Delta is nontrivial and not dominated by degeneracy.
5. The result survives removal of any one counted voice.
6. The result is not carried by one background model or one mask family.
```

Default percentile gate:

```text
primary tail <= 0.05 after the declared look-elsewhere accounting
```

Failure:

```text
Planck positive control fails,
or Fermi shared motion is ordinary under nulls,
or the effect follows mask geometry rather than sky reconstruction,
or the effect collapses when one voice/background/mask is removed.
```

Inconclusive:

```text
too few independent-enough voices,
unstable axis extraction,
insufficient exposure/model provenance,
foreground residuals too dominant for the declared low-order extractor,
or contradictory null behavior.
```

## 10. Sonification Rule

Sound enters only after the numeric SharedShift verdict is locked.

Allowed mapping family:

```text
axis longitude -> pitch class
axis latitude -> timbre or pan
mask transition -> chord progression
motion magnitude -> glide or interval
rotation-axis concentration -> beating or roughness
```

The sonification report must state:

```text
source quantity,
conversion rule,
preserved structure,
discarded structure,
numeric verdict before sound,
listener protocol if any.
```

The correct listening question is:

```text
Does the listener hear the recurrence that the numeric metric already found?
```

Forbidden listening question:

```text
Did hearing the note prove recurrence?
```

## 11. Allowed Claims

1. This document freezes a Fermi demask-shift recurrence experiment as an
   operator-residue test.
2. The experiment tests shared motion across reconstruction voices before
   sonification.
3. Fermi is used as an instrument-forward reconstruction domain.
4. A successful result would justify outside physics/statistics review of a
   cross-domain observer-reconstruction invariant candidate.
5. A failed result would reduce the recurrence concern under this contract and
   improve the boundary between numeric residue and perceptual mapping.

## 12. Forbidden Claims

1. Fermi currently supports AOC.
2. A heard note proves recurrence.
3. A shared demask shift proves a physical spin operator.
4. A shared demask shift proves doom, cosmological hazard, or ontological
   recurrence.
5. A Fermi residual pattern refutes LambdaCDM.
6. Endpoint clustering alone is evidence for a cross-domain invariant.
7. Post-hoc changes to voices, masks, low-order bands, or nulls may be counted
   as the predeclared result.
